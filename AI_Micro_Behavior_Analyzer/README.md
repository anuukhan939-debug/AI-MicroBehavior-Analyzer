 AI Micro-Behavior Analyzer

An AI-powered web application designed to analyze facial emotions, focus, and attention through webcam-based video processing. The system presents behavioral insights through interactive dashboards and session reports.

 Overview

The AI Micro-Behavior Analyzer aims to support real-time behavioral analysis using Artificial Intelligence (AI) and Computer Vision. It processes webcam video to identify facial emotions and estimate attention levels, helping users review behavioral metrics and session summaries.

 Key Features

- Real-Time Video Processing: Captures video through a user's webcam for analysis.
- Facial Emotion Recognition: Analyzes facial expressions to identify emotions.
- Focus and Attention Analysis: Estimates focus and attention using visual behavioral cues.
- Interactive Dashboard: Displays behavioral metrics and session insights.
- Session Management: Supports starting, monitoring, and reviewing analysis sessions.
- Reports and Analytics: Presents historical session information and analysis summaries.
- User Authentication: Provides access to system functionality based on user roles.
- Administration: Supports administrative views for reviewing users, sessions, and analytics.

 Main Modules

1. Authentication and Authorization
2. Webcam and Video Processing
3. Emotion Detection
4. Focus and Attention Analysis
5. Session Management
6. Analytics and Reporting
7. Administration

 Technology and Architecture

- Web Framework: Django
- Architecture: Django Model–View–Template (MVT)
- Application Type: Web-based application
- AI Domain: Artificial Intelligence and Computer Vision
